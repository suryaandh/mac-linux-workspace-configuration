# mac-linux-configuration

A collection of tools I built for my own use. Personal preferences for macOS and Linux.

## Tools

### [BrightnessBar](./BrightnessBar)
Menu bar app to control internal and external monitor brightness on macOS.

### [DynamicNotch](./DynamicNotch)
Dynamic notch overlay for MacBook, showing music info, notifications, and brightness in the notch area.

---

All tools are built from scratch with no external dependencies, using the macOS private APIs needed to get the job done.
